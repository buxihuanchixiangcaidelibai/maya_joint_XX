# Maya 四元数修型骨骼工具

适用于 Maya 2025。`QuaternionCorrectiveCreator.py` 创建修型驱动骨骼及对应蒙皮骨骼，并使用 Maya 2025 内置的 PySide6 提供中文界面；`CorrectiveKeyframeMirror.py` 镜像左右侧的修型属性关键帧和 Driven Key 曲线。本目录位于仓库根目录，与绳索绑定项目的 `scripts/` 目录分开。

## 手动上传到 GitHub

先解压下载的 ZIP，再把整个 `quaternion_corrective_tools` 文件夹上传到 `Maya_Rig_Python` 仓库根目录。仓库中应显示 `quaternion_corrective_tools/README.md` 和同目录下的两个 `.py` 文件；不要只上传 ZIP 文件。

## 启动

将仓库下载到本地，在 Maya 的 Script Editor **Python** 选项卡中运行。把下方路径改为本机仓库的 `quaternion_corrective_tools` 目录：

```python
import sys
sys.path.insert(0, r"C:\path\to\Maya_Rig_Python\quaternion_corrective_tools")

import QuaternionCorrectiveCreator as qcc
qcc.show()
```

打开关键帧镜像窗口：

```python
import CorrectiveKeyframeMirror as qkm
qkm.show()
```

若 Maya 中已导入旧版本脚本，先执行 `import importlib; importlib.reload(qcc)` 或 `importlib.reload(qkm)`，再调用 `show()`。

窗口右上角的“骨骼显示”开关可在“驱动”和“蒙皮”两种查看模式之间切换，打开工具时默认使用“驱动”模式。“驱动”模式显示工具生成的驱动组并隐藏蒙皮修型骨骼；“蒙皮”模式隐藏驱动骨骼并只显示带工具标记的蒙皮修型骨骼，不会隐藏整个蒙皮父级或角色的其他骨骼。工具首次切换时会把两类骨骼分别整理进专用显示层，之后只切换两个显示层的可见性，避免逐根骨骼刷新造成卡顿。显示切换支持 Maya Undo。

## 创建修型骨骼

窗口分为“创建”和“新增 / 重建”两个页签。第一次建立修型系统时使用“创建”页：

1. 在“场景对象”中读取表面网格。输入框默认留空，避免误用旧场景名称；驱动骨骼组可使用默认名称，不存在时工具会在场景根层级创建。生成的蒙皮修型骨骼会自动放在各自所选源关节下面，无需另外指定父级。
2. 在“创建参数”中选择旋转驱动轴、弯曲方向，并在“关节方向”中勾选 X、Y、Z 的一个或多个方向；默认勾选 Y。
3. 选择一个或多个源关节，点击“为选中关节创建修型骨骼”。

源关节获得 `quatCorrectiveWeight` 和每根 Pos/Neg 修型骨骼的位移倍数属性。`quatCorrectiveWeight` 的生成默认值和当前值均明确设置为 `+0.5`，支持之后手动调整为正负值。位移倍数只缩放旋转产生的位移；源关节未弯曲时，改变倍数不会产生位移。工具不会自动修改 skinCluster 或刷权重。

自动创建时，工具会从源关节位置沿每个勾选自身轴的正、负方向分别发射射线，并把两侧修型骨骼放在模型的第一个表面交点。同一源关节始终只创建一套 `QuatBlend_GRP` 和 `QC_ROOT`：勾选 X、Y、Z 时，会在这套根系统下生成 PosX／NegX、PosY／NegY、PosZ／NegZ 共六根表面驱动骨骼及六根对应蒙皮骨骼。工具会在建节点前先验证所有勾选方向都能命中模型，避免留下半成品。`QuatBlend_GRP` 保存与原始绑定关节一致的中立轴向，并只跟随源关节父级的整体朝向；源关节自身的局部 `rotate` 经过 `eulerToQuat → quatSlerp → quatToEuler` 后连接到组下的 `QC_ROOT`。高级设置中的“最大表面投射距离”决定射线搜索上限。

生成的驱动根骨骼、表面驱动骨骼和蒙皮修型骨骼，其 Maya `radius` 默认等于对应原始绑定关节的 `radius + 0.5`，便于在视图中识别和选择。

一次点击创建产生的驱动组、所有方向骨骼、计算节点、显示层、层成员和最终选择会统一记录为一个 Maya Undo Chunk。无论只勾选一个方向还是同时勾选 X/Y/Z，都只需执行一次 Undo 即可恢复到点击创建之前。

要手动新增修型骨骼，可先从蒙皮骨架复制一根关节并摆到需要的位置，再选择这根摆放骨骼，最后加选负责旋转的源关节并点击“建立驱动”。工具会把第一根骨骼保持世界位置不变地转换成驱动骨骼，并放入同一修型区域的 `QC_MANUAL_DRV_GRP` 稳定父级；同时在第一根骨骼原来的蒙皮父级下创建同位置的 `QC_SKIN_JNT`，建立驱动骨骼到蒙皮骨骼的父级与缩放约束。稳定父级和 `QC_DRV_ROOT_JNT` 位于同一个四元数参考组中：它完整跟随源关节的位置、正常旋转和缩放，但不继承 `QC_DRV_ROOT_JNT` 上由 `quatCorrectiveWeight` 产生的加权或反向旋转。因此倍率为 `0` 时骨骼仍会正常跟随肢体，只是不产生额外修型位移。可用界面中的附加位移轴选择实现多轴位移。要重设修型骨骼的位置，使用“断开位移”，调整后点击“保存并重连”。

自动系统创建 `QC_DRV_ROOT_JNT` 时，会用 Maya message 属性显式记录它对应的源关节。新增驱动通过这条连接查找归属位置，不依赖骨骼名称；旧场景没有该记录时，会先根据既有约束关系识别一次并自动补写，因此之后重命名源关节或驱动根骨骼也不会丢失对应关系。

工具会在修型骨骼上记录旋转驱动轴、主移动轴，以及 X／Y／Z 中实际参与移动的轴。保存并重连默认只更新基础位置，不改变这些记录；一根骨骼由同一个旋转同时驱动两个或三个移动轴时，原有的多轴连接会全部保留。旧版本生成的兼容节点会在首次重连或补加位移轴时自动补写记录。

手动新增骨骼的驱动连接仍集中在“新增 / 重建”页；“断开位移 / 保存并重连”已放到“驱动管理”页顶部，便于调整倍率时直接重设表面修型骨骼的位置。紧邻按钮的“重算方向”复选项用于保存时根据当前位置重新计算单轴移动方向，默认关闭；补加位移轴仍在“新增 / 重建”页中默认折叠。该页的新增骨骼参数独立于“创建”页。

“建立驱动”成功后会自动重新扫描驱动管理页，展开对应源关节并定位到刚创建的驱动项目，无需再手动点击“扫描场景”。

旧版手动新增骨骼的主倍率属性名可能没有写入位移轴。管理页会改读骨骼上记录的主移动轴，将这类倍率归回对应骨骼行，而不是错误地放进“系统设置”。

手动新增网络使用隐藏属性 `qcManualDriveVersion` 记录版本。再次对已有手动驱动执行“建立驱动”时，版本等于当前版本就保留现有网络；没有版本记录或版本较旧时，只删除并重建该骨骼私有的位移计算节点。版本 3 还会把原本直接位于旋转 `QC_DRV_ROOT_JNT` 下的新增骨骼迁移到稳定父级：稳定父级直接跟随源关节完整变换，而不读取加权四元数根，因此倍率为 `0` 时只有正常骨架跟随，没有额外修型位移。驱动骨骼、蒙皮骨骼、父级／缩放约束、原倍率属性及其数值或动画连接均会保留。升级后会补写当前版本，避免以后重复重建。

顶部的“删除所选骨骼及链接”支持两种范围：选择 Pos／Neg 驱动骨骼或对应蒙皮骨骼时，只移除该方向；选择 `QC_DRV_ROOT_JNT` 父级根骨骼或对应蒙皮根骨骼时，删除它下面的全部方向以及整套共享根系统。确认后会清理对应蒙皮骨骼、约束、位移与四元数计算节点，以及不再使用的倍率属性。整个操作可以使用 Maya Undo 撤销。

新增骨骼驱动参数说明：

- “读取哪个旋转通道”：驱动父级旋转时实际变化的 `rotateX`、`rotateY` 或 `rotateZ`。
- “修型骨骼移动方向”：选择连接前新增修型骨骼自身的局部 X、Y 或 Z 轴。
- “每旋转 1° 移动多少”：父级旋转变化量与修型骨骼移动距离的换算值，负数会反转移动方向。
- “同时向其他方向移动”：在主轴之外，沿新增修型骨骼自身的其他局部轴叠加位移。

新增驱动不再要求预先判断关节只向哪一侧旋转。正负旋转变化都会被保留，并以建立连接时的位置、朝向和父级旋转作为基准，因此连接后骨骼不会跳位。界面中的“自身 +X / +Y / +Z”与 Maya 显示的修型骨骼局部轴一致：父级旋转通道相对起点增加时沿所选正轴移动，减少时沿对应反轴移动；若需要把这组关系整体反过来，直接将“每旋转 1° 移动多少”改为负数。工具会通过 Maya 实际求值的 Translate X/Y/Z 基向量换算所选自身轴，因此能够兼容 `jointOrient`、`rotateAxis`、`offsetParentMatrix`、镜像和非等比缩放，避免把所选轴误解成简单的父空间轴。修改脚本前已经建立的新增驱动需要重新点击“连接所选骨骼”来重建方向向量。

全新建立的手动新增驱动，其每个移动轴倍率默认值和生成值均为 `0`。因此建立后即使旋转源关节，修型骨骼也不会产生位移；之后可在“驱动管理”页逐步调节滑块确定合适倍率。自动创建的 Pos／Neg 修型骨骼以及“补加自动修型位移轴”仍保持原来的默认倍率，不受此设置影响。升级旧版新增网络时会保留原倍率，不会强制清零。

如果已有自动修型骨骼还需要叠加其他位移轴，可在“新增 / 重建”页使用“补加自动修型位移轴”：

1. 选择自动生成的 Pos / Neg 表面修型驱动骨骼，或对应的蒙皮修型骨骼。
2. 勾选缺少的源关节局部 X、Y 或 Z 轴，并设置每旋转 1° 的基础位移。
3. 点击“为所选自动修型补加位移轴”。工具会在原有旋转驱动上增加新分支，并在源关节创建对应的 `qcPos/Neg*MoveX/Y/ZMultiplier` 属性。

已经存在的轴和当前系统的主位移轴不会重复创建。新属性可在“驱动管理”页重新扫描后集中调节。

## 驱动数值管理

“驱动管理”页用于集中调整生成后的修型权重和位移倍率：

- 可读取当前选择的源关节，也可扫描整个场景中的修型驱动属性。
- 按关节折叠分组，默认避免同时展开大量修型项目。
- 支持搜索关节、修型骨骼和属性名，并可只显示已修改的数值。
- 列表改为“源关节 → 驱动项目”两层显示。展开一次源关节后，每一行直接显示完整 Maya 骨骼名、输入与输出关系以及倍率滑块，例如“Hip_L_QC_DRV_JNT_NegZ | 旋转 Z → 位移 Z”；不再需要逐根展开中间骨骼层。多轴骨骼会直接显示成多行，完整属性、输入和输出继续保留在鼠标提示中。
- 顶部依次提供“断开位移”、“保存并重连”和“重算方向”，作用于 Maya 当前选择的自动修型骨骼；可在断开后调整位置，再保存当前位置并恢复位移驱动。“重算方向”只改变单轴骨骼后续的移动方向，多轴骨骼始终保留原有全部移动轴。
- 每项提供滑块、精确数值框、临时归零和恢复生成默认值按钮。
- 对带移动轴的驱动项单击右键，可从当前连接对象的 `rotateX/Y/Z`、`translateX/Y/Z`、`scaleX/Y/Z` 中单选一个输入通道。菜单出现后再次按右键（连续按两次右键）或点击菜单底部的“更换连接对象…”，都会打开对象输入框，也可使用“读取当前选择”更换输入对象。普通左键双击仍只负责在 Maya 中选择对应修型骨骼。
- 每个移动轴保存独立的连接对象与输入通道。旋转和位移通道以 `0` 为中性值，缩放通道以 `1` 为中性值；输入处于中性值时，调整倍率不会直接移动修型骨骼。新增轴默认沿正轴移动，正负方向继续由倍率滑块控制。
- 自动修型骨骼采用 `源关节_QC_DRV_JNT_主方向_附加轴` 命名，例如 `Hip_L_QC_DRV_JNT_NegZ_Y`；对应蒙皮骨骼为 `Hip_L_QC_SKIN_JNT_NegZ_Y`。主方向保留 Pos／Neg，附加轴只记录 X／Y／Z，不随倍率正负改名。
- 可展开或折叠全部分组；双击项目会在 Maya 场景中选择对应关节。
- “重置当前可见项”只影响搜索和过滤后仍然可见的驱动项目，并可通过 Maya Undo 撤销。

管理页显示的是修型权重和位移倍率，不是骨骼最终的 `Translate` 数值。最终位移由基准位置、驱动输入、创建或补加时设置的每度基础位移以及倍率共同计算。工具会沿实际节点连接识别骨骼当前名称、输入通道和移动轴；骨骼重命名后重新扫描即可更新。补加成功后管理页会自动重新扫描，无需手动点击“扫描整个场景”。

双击驱动项目时会根据右上角的显示模式选择场景节点：“驱动”模式选择对应表面驱动骨骼，“蒙皮”模式选择由该驱动骨骼约束的蒙皮修型骨骼；双击关节分组标题仍选择源关节。新版手动新增骨骼同样会生成并记录独立的驱动／蒙皮骨骼映射。

## 镜像关键帧

先确保两侧源关节及对应属性存在。在镜像工具中选择 `_L → _R` 或 `_R → _L`，选择源关节并执行。工具也提供直接镜像默认 Knee/Elbow 关节的按钮。它会复制修型权重、位移倍数和修型骨骼位移的时间关键帧，并用对侧驱动属性重建修型倍数的 Driven Key 曲线。目标属性已有的动画曲线会被替换，执行前请保存场景备份。

## 文件

- `QuaternionCorrectiveCreator.py`：创建、编辑和手动连接修型骨骼。
- `CorrectiveKeyframeMirror.py`：左右修型关键帧及 Driven Key 镜像。

本工具依赖 Maya 内置 `maya.cmds`、`maya.api.OpenMaya` 和 `quatNodes` 插件，无需额外 Python 包。
